03 / Prompts

Keep it consistent.

A self-contained logo prompt and eight asset briefs describe the actual selected identity. No reference attachment is required for the logo prompt. Published assets should reuse the supplied PNG master. SVG layouts embed this image rather than tracing it into vectors.

Logo promptAll asset promptsBrand tokens
What does the prompt pack cover?

Logo exploration, store tile, marquee, connection illustration, Open Graph image, repository card, real screenshot composition, and a future landing-page handoff. This guide is a local asset preview; no website or store listing has been published.

How do I regenerate the artwork?

Install the build-only dependencies from branding/requirements.txt, then run python3 branding/build.py. The bundled Geist font supplies the typography. Rendering artwork does not start Chrome or run extension tests.
