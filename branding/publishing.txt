EXTENSION PACKAGE

Ready: extension/icons/icon-16.png, icon-32.png, icon-48.png, icon-128.png.
These are wired into manifest.json. Chrome manifest icons need raster images;
SVG files are editable masters for the brand, not manifest icon replacements.
Upload only the extension folder as the extension ZIP, not this entire repository
or the brand-kit archive. Run npm run build:helper before packaging: the
local-helper/ folder carries the Node helper source for the coding agent to
install outside Chrome. The extension first shows a copyable agent setup prompt.
The agent can download the matching bridge ZIP and SHA256SUMS from
https://github.com/guilhermegm/browser-profile-mcp/releases . Bundled helper
source remains a fallback. Node is a local runtime requirement; the setup
agent checks and installs it as needed. npm run build:release packages the
bridge and extension with explicit file allowlists and no runtime credentials.
Branding assets alone do not constitute a complete CWS submission: review
functionality, permission justifications, privacy practices, support information,
distribution settings, and the actual captures before publishing.

BRAND USAGE

Name: Browser Profile MCP (keep this order and spelling).
Tagline: Your browser, your coding agent.
Mark: Proboscis Monkey, the supplied orange monkey with browser and MCP folders.
Source: logo/monkey-source.png, preserved byte for byte. Keep its original colors,
proportions, and original transparent background. Exports resize the supplied artwork
without adding a background or recoloring it.
Use the supplied 128 px CWS icon with its 16 px transparent outer padding.
Type: Geist 650 for the identity and headlines; 450 for body copy.
The variable font is bundled locally under the SIL Open Font License; see
fonts/OFL.txt. Exported SVG text is outlined and the monkey PNG is embedded.
The extension loads its own local font file without external font requests.
Keep the supplied artwork and proportions. Do not add extra symbols,
effects, backgrounds, or unverified product claims.
Colors: Signal #F15B3A, Ink #17181B, Paper #FAF9F6, Quiet #64666B.
Use Ink on Paper for text, Paper on Ink for dark banners. Keep the monkey in full
color on both. Signal remains an accent for cursor activity and focus indicators.
Do not fill every interface control with the accent.

Regenerate assets with: python3 branding/build.py
Build-only dependencies: Pillow and FontTools (see requirements.txt).
The generator uses the bundled Geist font; no system font installation is needed.
The generator renders artwork and packages it; it does not run extension tests.
